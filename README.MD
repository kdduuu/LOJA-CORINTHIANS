# Loja Corinthians

Aplicação web desenvolvida com Flask e MySQL para gerenciamento de produtos.

---

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Edição de produtos
- Exclusão de produtos

---

## Tecnologias Utilizadas

- Python
- Flask
- MySQL
- HTML5
- CSS3
- Jinja2
- Git
- GitHub

---

## Objetivo

Projeto desenvolvido para estudo de desenvolvimento web backend utilizando Flask e integração com banco de dados relacionais.

Durante o desenvolvimento foram aplicados conceitos como:

- Rotas Flask
- Templates Jinja2
- CRUD completo
- Integração com MySQL
- Manipulação de formulários
- Versionamento com Git
